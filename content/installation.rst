OTOBO Installation
==================

This chapter describes the installation and basic configuration of the central OTOBO framework.
Currently, the recommended installation method is using Docker and Docker Compose.
However, it is also possible to install OTOBO manually on a standard Linux server directly.
Please refer to any subsection for your preferred installation method.
